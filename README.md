# AI Support Chatbot — Production RAG Demo

A production-ready AI customer support agent that answers questions from a real knowledge base using RAG (Retrieval-Augmented Generation).

**Live demo:** [ai-support-chatbot.vercel.app](https://ai-support-chatbot.vercel.app)

## Stack

- **Next.js 14** — frontend + API routes (App Router)
- **OpenAI GPT-4o-mini** — chat completions with streaming
- **OpenAI text-embedding-3-small** — query and document embeddings
- **Pinecone** — vector database for knowledge retrieval
- **Tailwind CSS** — styling
- **Vercel** — hosting
